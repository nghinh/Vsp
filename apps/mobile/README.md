# Mobile App — Vietnam Smart Golf Platform

## Overview

Flutter mobile application providing golfers with GPS distances, offline course packages, hole maps, scorecard, and course condition data.

## Tech Stack

- **Framework**: Flutter (SDK constraint >=3.10.0)
- **Maps**: MapLibre Flutter
- **Local Storage**: SQLite, encrypted storage for auth tokens

## Repository Structure

```
apps/mobile/
├── lib/              # Flutter app source (deferred to later stories)
├── test/             # Flutter tests (deferred)
├── android/          # Android platform (generated by flutter create)
├── ios/              # iOS platform (generated by flutter create)
├── pubspec.yaml      # Flutter dependencies
└── README.md
```

## Bootstrap

### Prerequisites

1. **Flutter SDK** (>=3.10.0)
   - Install from: https://docs.flutter.dev/get-started/install
   - Verify: `flutter doctor`

2. **Xcode** (macOS, for iOS development)
   - Install from Mac App Store
   - Run `sudo xcodebuild -license` to accept the license

3. **Android SDK** (for Android development)
   - Flutter bundles the Android SDK by default
   - Or install separately via Android Studio

### Setup Steps

1. **Clone and navigate:**
   ```bash
   cd apps/mobile
   ```

2. **Run flutter doctor** (verifies toolchain):
   ```bash
   flutter doctor
   ```
   Address any issues reported before proceeding.

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the app:**
   ```bash
   # iOS Simulator (macOS only)
   flutter run -d <simulator_id>

   # Android Emulator
   flutter run -d <emulator_id>

   # List available devices
   flutter devices
   ```

### Automated Bootstrap

Instead of manual steps above, run the master bootstrap from the repository root:

```bash
./infra/scripts/bootstrap.sh
```

This checks prerequisites (Flutter, Docker, git), starts local services, and runs `flutter pub get`.

Or run Flutter-specific setup only:

```bash
./infra/scripts/bootstrapFlutter.sh
```

### IDE Setup

- **VS Code**: Install the "Flutter" extension, open `apps/mobile/`
- **Android Studio / IntelliJ**: Install Flutter plugin, open `apps/mobile/`
- **iOS (macOS)**: Open `apps/mobile/ios/Runner.xcworkspace` in Xcode

## Development

Run `flutter doctor` to verify Flutter SDK and toolchain setup before every development session.

Run `flutter run` to start the development emulator/simulator.

## Environment Variables

Copy `.env.local.example` from the repository root to `.env.local` and fill in required values:

```bash
cp .env.local.example .env.local
# Edit .env.local with your values
```

See `.env.local.example` for all required keys. Never commit `.env.local` to version control.

## Local Services

PostgreSQL (PostGIS) and Redis are required for full-stack development. Start them with:

```bash
./infra/scripts/runLocalServices.sh
```

Stop them with:

```bash
./infra/scripts/stopLocalServices.sh
```
