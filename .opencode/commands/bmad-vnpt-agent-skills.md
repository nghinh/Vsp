Use this pack when you need a focused VNPT engineering skill:

- `vnpt-generate-prd`
- `vnpt-tdd`
- `vnpt-triage-bug`
- `vnpt-improve-architecture`
- `vnpt-design-interface`
- `vnpt-domain-model`
- `vnpt-qa-review`

Do not use this command as an orchestrator. Select the smallest suitable skill and follow its `SKILL.md`.
